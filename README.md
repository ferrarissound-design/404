# 404号室：帰宅記録

深夜の古いマンション「404号室」に帰宅する、一人称視点の **3D心理ホラー**（体験版・約8〜12分）。

ブラウザだけで遊べます（インストール不要）。iPhone / iPad の Safari、Android の Chrome、PC の主要ブラウザに対応。

> 突然の大音量や化け物で驚かせるゲームではありません。
> 日常の小さな違和感と、何も起きない時間、そして **自分の記憶を疑う恐怖** を描きます。

---

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 左半分をドラッグ（仮想スティック） | `W` `A` `S` `D` / 矢印キー（`Shift` で早歩き） |
| 視点 | 右半分をドラッグ | マウス（クリックでポインタロック） |
| 調べる・開閉 | 物をタップ / 右下の「調べる」ボタン | `E` / `Space` / クリック |
| スマートフォン | 右上の端末アイコン | `M` |
| ライト（停電時に入手） | 右上のライトアイコン | `F` |
| メニュー | 右上の ≡ | `Esc` |

* 横画面でのプレイを推奨します（縦画面では「横向きにしてください」を表示）。
* ヘッドホン推奨。音はすべてブラウザ内で合成しており、外部の音声ファイルは使っていません。
* 自動保存あり。タイトル画面の「つづきから」で再開できます。
* 設定で、音量（全体/環境音/効果音）・視点感度・画質・**点滅表現の抑制**・振動を変更できます。

## ゲームのしくみ

基本ループは「探索 → 配置を記憶 → 物音をきっかけに廊下へ → 戻ると何かが変わっている → 調べて、自分の記憶を信じるか疑うかを決める」です。

### 部屋はあなたを観察している
行動はゲーム内部で記録され（本物の機械学習は使わず、軽量な集計とイベント選択のみ）、後半の怪奇現象に反映されます。

* **視線ログ**：画面中央で何をどれだけ見つめたか（0.12秒刻み）
* **調査ログ**：何を調べたか、どの扉を開けたか、照明をどう触ったか、どの部屋に何秒いたか
* **判断ログ**：変化に対して「確かに違う（信じる）」か「気のせいだ（疑う）」か
* 最も見つめた/調べたものに対応する怪異（時計・写真・窓・ベッド・冷蔵庫・テレビ…）が優先して発生します。
* 判断は世界に影響します。
  * **信じた**項目 → 世界のほうが元に戻る（「じゃあさっきのは何だった？」と記憶のほうを疑わせる）
  * **疑った**項目 → 見過ごした違和感が、より明白な形で戻ってくる
* エンディングでは「この部屋が観察していたあなた」として記録を表示します。

### 恐怖の設計
* 何も起きない時間（クールダウン）と、**空振りの予兆**（物音だけで何も起きない）を意図的に挟みます。
* 不自然な静寂（環境音を一瞬だけ落とす）、視界の端に一瞬映って見ようとすると消える人影、閉めたはずの扉、増えるマグカップ、変わる家族写真……。
* 部屋に戻る瞬間は、玄関ドアが閉まって室内が見えない間にだけ世界を書き換えます（プレイヤーは変化の瞬間を見ません）。
* 廊下は帰宅のたびに少しずつ長くなります。

### 体験版の構成（全3幕）
プロローグ → 第1幕（帰宅1回目・何も変わらない）→ 共用廊下 → 第2幕（通知「帰宅回数：7」・変化の発生と判断）→ 共用廊下（足跡・エレベーター）→ 第3幕（見つめたものへの怪異・停電）→ 結末（2種類）。

## 技術構成

| 項目 | 内容 |
|---|---|
| 描画 | Three.js (WebGL2) / Vite |
| 質感 | すべて手続き生成テクスチャ（フローリング・壁紙・コンクリート・金属・布…）＋ PBR（粗さ・バンプ・環境反射） |
| 照明 | 部屋ごとのライトマスク（シェーダ差し替え）で光漏れを防止、LDKのみ影付きスポット、蛍光灯のちらつき、間接光の近似、接地影デカール |
| ポスト処理 | HDR(HalfFloat)・MSAA・ブルーム・ACESトーンマップ・色収差・フィルムグレイン・ディザ（暗部の階調保持）・ビネット |
| 音響 | Web Audio による全合成（蛍光灯のうなり、冷蔵庫、足音、遠い足音、ノック、オルゴール、ハミング…）、空間音響・壁越しのローパス・合成IRの残響 |
| 画質調整 | 初回に端末種別から推定＋実行中のフレーム時間で動的解像度/段階ダウン（設定で固定可） |
| 保存 | `localStorage`（自動保存・再開・設定） |

素材はすべてコード内で生成しているため、外部アセットのライセンス問題はありません。使用ライブラリは [Three.js](https://threejs.org/)（MIT）のみ。

## 開発

```bash
npm install
npm run dev       # 開発サーバ（スマホ実機確認は同一ネットワークから Network URL へ）
npm run build     # dist/ に本番ビルド
npm run preview
```

### 自動テスト
`tests/smoke.mjs` は Playwright（ヘッドレス Chromium・ソフトウェアGL）で、タイトル→プロローグ→第1幕→共用廊下→第2幕→第3幕→停電→結末までを内部デバッグ API で進行させ、重大なエラーが出ないこと・各フェーズに到達できること・セーブ/再開が機能することを確認します。

```bash
npm run build && npm run preview &   # 別ターミナルで
BASE_URL=http://localhost:4173/ npm test
```

#### 自動テストで確認できる範囲 / 実機確認が必要な範囲
| 自動（CI・ヘッドレス）で確認 | 実機確認が必要 |
|---|---|
| ビルド成功、起動、全フェーズの進行、ENDING到達、セーブ/再開、実行時エラーなし、描画コール数/ポリゴン数 | iPhone/iPad Safari・Android Chrome の実フレームレート、発熱、メモリ |
| 怪奇現象の発生（状態変化・ログ記録）、分岐（信じる/疑う）の反映 | 仮想スティック・視点操作・タップ判定の感触（親指の届き、誤タップ） |
| UI の表示（タイトル/設定/ポーズ/調査/選択/スマホ/エンディング） | 音の実際の聞こえ方（ヘッドホン/スピーカー、iOSのマナーモード挙動） |
| | 画面の明るさ・暗部の見え方（端末ごとのディスプレイ差） |

## 公開（GitHub Pages）
`.github/workflows/pages.yml` が `main` への push で `dist/` を GitHub Pages にデプロイします（リポジトリの Settings → Pages → Source を「GitHub Actions」に設定）。`base: './'` なので任意のサブパスで動作します。
